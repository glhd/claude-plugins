# glhd-plugins

A Claude Code plugin marketplace from [Galahad, Inc.](https://github.com/glhd)

Add it once:

```
/plugin marketplace add glhd/claude-plugins
```

Then install what you want.

## Plugins

| Plugin | What it does |
| --- | --- |
| [plain-prose](plugins/plain-prose) | Plain-language prose rules, with periodic reminders as the conversation grows. `/plugin install plain-prose@glhd-plugins` |
